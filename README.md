# Certify — Certificate Management System

A polished, dependency-free frontend prototype for certificate providers and teachers.

## Run it

Open [index.html](index.html) in a browser, or serve this folder with any static web server. No build step is required.

## Included workflows

- Welcome and provider sign-in screen
- Course creation and management
- Batch creation with configurable batch letter and year
- Automatic roll numbers in the format `X26B001`
- Add learners one at a time and keep certificate drafts
- Course-level certificate design setup
- Default certificate design and blank certificate upload flow
- Student-name position and font controls
- Individual and bulk certificate issuing
- Public verification-link preview
- Payment and hosting placeholders for individual, selected, or batch certificates

Data is stored in browser local storage for this prototype. The UI has clear seams for connecting a backend, file storage, CSV imports, authentication, payments, PDF generation, QR codes, and public verification routes.
